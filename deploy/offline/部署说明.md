# 计划审核 · 公司服务器离线安装

适用 Linux x86_64 服务器，预装 Docker Engine、Docker Compose v2 和 flock。包内含应用和 MySQL 8.4.8 镜像、编译好的前端、Python 依赖和两份空白模板。建议预留至少 4 GB 可用内存和 5 GB 可用磁盘，业务文件、备份和日志另计。

## 首次安装

完整解压发布包，在解压目录执行：

```sh
sudo sh server.sh install
sudo sh server.sh status
sudo cat /var/lib/easphub-plan-review/secrets/initial-admin-password
```

首次安装会校验文件、导入镜像、初始化 MySQL、建立管理员账号并启动 web 和 worker。账号为 `admin`。初始密码仅保存在该服务器，首次登录后请在个人菜单修改。管理员通过「管理 → 人员与权限」添加计划员、复审员、数据维护员及各仓权限。十个市场已经登记，快照、计划和其他用户从空库开始。

## 公司同事的访问入口

服务默认仅在服务器的 `127.0.0.1:3350` 提供后端入口。请将公司已有的 **HTTPS** 域名接入反向代理，再把 `https://公司域名/apps/plan-review/` 发给同事。正式登录需要 HTTPS。

宿主机 Nginx 可将下列配置放在已有的 HTTPS server 中，然后用 `nginx -t` 检查并平滑重载：

```nginx
location = /apps/plan-review {
    return 308 /apps/plan-review/$is_args$args;
}
location ^~ /apps/plan-review/ {
    proxy_pass http://127.0.0.1:3350;
    proxy_set_header Host $http_host;
    proxy_set_header X-Forwarded-For $remote_addr;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_read_timeout 120s;
    client_max_body_size 21m;
}
```

若公司 Nginx 本身在 Docker 内，首次安装时可指定它所在的用户定义网络：

```sh
sudo env PROXY_NETWORK=company-proxy sh server.sh install
```

在该代理的 HTTPS server 中包含本包 `deploy/nginx-location.company.conf` 的两个 location，然后验证和重载。文件中使用容器网络别名 `plan-review-company-web:3350`。服务器包会连接指定网络；对外域名、证书和代理配置由公司维护。MySQL 端口只在应用私有网络可用。

首次安装可用 `HTTP_PORT=13350` 指定空闲的本机端口。可用 `STATE_DIR=/srv/plan-review` 指定专用空目录，后续 start、stop、status、logs 均传相同的 STATE_DIR。宿主机 Nginx 请填写对应的本机端口。

## 运维

从 v2.0.0 更新时，先按下文备份数据。将新版解压到新的程序目录，使用原来的 `STATE_DIR` 运行 `sudo sh server.sh install`。安装器沿用现有账号、附件、数据目录和代理设置，更新应用镜像并执行数据库迁移。

```sh
sudo sh server.sh status
sudo sh server.sh logs
sudo sh server.sh stop
sudo sh server.sh start
```

业务数据和配置默认在 `/var/lib/easphub-plan-review`。冷备时执行 stop，使用具备访问控制的备份介质保存整个数据目录（含 MySQL、导入附件、app.env、secrets 及隐藏文件），保留属主和权限，然后执行 start。恢复时使用同一发行包、数据路径和配置，保持服务停止，将完整冷备恢复到专用空目录再运行 install。安装可重复执行，已初始化的账号和数据会继续使用。控制台显示的默认初始密码文件只用于首次登录。

公司服务器安装要求 root 或 sudo 权限；管理员、数据库密码均首次现场生成。工作电脑可直接通过浏览器访问公司域名。
